// System Windows.UI.Composition bindings for the self-hosted DirectComposition
// HDR backend. Generated into its OWN module (system_bindings.rs), flat+minimal,
// so the short names (Compositor, Visual, DispatcherQueue, ...) do NOT collide
// with the lifted Microsoft.UI.Composition types in bindings.rs.
//
// Comments must start at column 0 (--etc only strips lines beginning with `//`).
//
// This file is the single source of truth for system_bindings.rs — regenerate
// with `cargo run -p tool_reactor`. Keep it in sync with every symbol the
// dcomp backend consumes; the historical drift (an uncommitted richer filter
// carrying the retired D2D1Exposure/effects surface) was reconciled by adding
// the still-used entries below and letting the dead effect bindings go.

// ── Animations ──

// all compositor-evaluated: the app starts them and goes idle (no ticks).

// per-visual opacity (used by exit ghosts; the enter-side flatten can reuse it).

// to any size with pristine corners — the retained-part (chrome parts) fill.

// ── Clips ──
// ── Vector shapes (Knob value arc: a stroked path grown by an animated TrimEnd;
//    retained control chrome: rounded-rect / ellipse primitives. Shapes are
//    always the MASK — the FP16 surface is the source, see the mask brush) ──
// Mask brush for the knob value arc: the FP16 display-mapped gradient SURFACE

// live through a CompositionVisualSurface. Keeps the whole arc in the FP16 pipe.
