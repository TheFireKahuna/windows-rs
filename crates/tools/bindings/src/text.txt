// DirectWrite: shaping, measurement, and the coverage rasterizer. No Direct2D — a
// coverage tile is produced on the CPU by `IDWriteGlyphRunAnalysis`, and the crate
// that draws text owns its own Direct2D surface.

// The glyph-run walker implements a DirectWrite text renderer so that a shaped
// `IDWriteTextLayout` can be replayed as individual glyph runs — the input a run
// rasterizer needs. `IDWriteTextRenderer` derives from `IDWritePixelSnapping`, so
// both need `_Impl` scaffolding for the callback object to be constructible. The
// canonical Win32 metadata is a flat `Windows.Win32` namespace, so these name the
// interface directly under it — a stale sub-namespace here silently matches nothing
// and the scaffolding is simply not emitted.
--implement
    Windows.Win32.IDWriteTextRenderer
    Windows.Win32.IDWritePixelSnapping

// ── Resolving a face ──────────────────────────────────────────────────────────
// A shaped run crosses the app→front seam as plain data naming a font by an
// interned family id, so the *front* half resolves that id to a face and caches it.
// The system collection is the whole of the lookup: family name in, one face out at
// the requested weight, style and stretch. There is no custom font set here — an
// application ships its ladder as system-installed families or as a collection this
// crate does not yet build.
    IDWriteFontCollection::{FindFamilyName, GetFontFamily}
    IDWriteFontFamily::GetFirstMatchingFont
    IDWriteFont::CreateFontFace
    IDWriteFontList
    DWRITE_FONT_WEIGHT
    DWRITE_FONT_STYLE
    DWRITE_FONT_STRETCH
// Fallback resolves a face the requested family does not name, and glyph indices are
// face-specific — so a segment naming only what was *asked for* renders the fallback
// run's ids through the wrong face. The app half therefore reads back what DirectWrite
// actually chose and interns it; the front half resolves that description through the
// lookup above. Nothing else here round-trips.
    IDWriteFontFace3::{GetFamilyNames, GetWeight, GetStyle, GetStretch}
    IDWriteLocalizedStrings::{GetStringLength, GetString}

// ── The coverage rasterizer ───────────────────────────────────────────────────
// Rasterizes a glyph run to a CPU alpha texture. This is the whole static-text
// path: one coverage tile per run, alpha only, keyed on the scale it was rasterized
// at. It is also the only way to observe what the rasterizer actually produced — a
// composition surface has no read path, so without this "the glyph landed where we
// asked" is unfalsifiable.
    IDWriteGlyphRunAnalysis::{GetAlphaTextureBounds, CreateAlphaTexture}
