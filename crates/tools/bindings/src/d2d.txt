// Direct2D, and the Direct3D 11 / DXGI surface a D2D device is built on. DirectWrite
// appears here only where a Direct2D signature names it — a glyph run to fill. The
// shaping and rasterizing side belongs to `windows-text`, and a run crosses between
// them as plain data rather than as a DirectWrite struct.
//
// Every entry has a consumer in the wrapper. Four capability families are deliberately
// absent, each refused where it would have gone: swap chains and composition drawing
// surfaces as presentation models (`windows-present` owns the one path), display colour
// capability (`DisplayInformation` in `windows-window` — DXGI cannot report an SDR
// display with advanced colour), PQ colour contexts, and a multi-threaded device.

// ── Drawing session ───────────────────────────────────────────────────────────
// `SetTarget` is what lets one open bracket render a cached intermediate and then go
// back to the frame's own target, which is why a cached layer needs no context of its
// own. `SetRenderingControls` is issued once at device construction so an effect graph
// built later cannot inherit Direct2D's default limited-range intermediates; the two
// `Is*` probes are how "no fallback" is honoured — a device that cannot do FP16 fails at
// construction instead of silently rendering in 8 bits.
// `GetRenderingControls` is paired with the setter deliberately: the struct also carries
// a tile-allocation size, and zero is rejected outright (D1146), so the only way to
// change precision without inventing a tile size is to read what Direct2D chose and put
// it back.
    ID2D1DeviceContext::{CreateBitmap, CreateBitmapFromDxgiSurface, SetTarget, DrawBitmap, CreateBitmapBrush, CreateGradientStopCollection, SetPrimitiveBlend, GetRenderingControls, SetRenderingControls, SetUnitMode, IsDxgiFormatSupported, IsBufferPrecisionSupported, PushLayer, DrawGlyphRun}

    ID2D1DeviceContext2::{}
    ID2D1DeviceContext3::{CreateSpriteBatch, DrawSpriteBatch}
    ID2D1DeviceContext4::{}

// `EndDraw`'s tag out-parameters name the call that latched an error. One bracket spans
// every region in a present pass, so without tags a draw that vanished is
// indistinguishable from one killed by an earlier region's failure. `SetTags` is issued
// once per retarget, never per primitive.
//
// `DrawText`/`DrawTextLayout` are absent on purpose: text reaches the screen as a
// coverage tile or a cached bitmap, both rasterized through `DrawGlyphRun`, and a
// layout-drawing call here is an invitation to put DirectWrite on the live path.
//
// `SetTextRenderingParams` is here for the opposite reason. `DrawGlyphRun` takes no
// options parameter, so the *only* way to state how coverage is rasterized is on the
// context — and left to inherit the system's parameters, a coverage tile comes out
// systematically thin or fat and reads as a font choice rather than as a setting.
// The params object itself is DirectWrite's and is built by `windows-text`; this
// crate names only the interface, so that a caller can hand one over.
    ID2D1RenderTarget::{BeginDraw, EndDraw, SetTags, Clear, DrawEllipse, FillEllipse, DrawLine, DrawRectangle, FillRectangle, DrawRoundedRectangle, FillRoundedRectangle, DrawGeometry, FillGeometry, CreateSolidColorBrush, CreateLinearGradientBrush, CreateRadialGradientBrush, GetTransform, SetTransform, SetDpi, GetDpi, GetPixelSize, PushAxisAlignedClip, PopAxisAlignedClip, PopLayer, SetTextAntialiasMode, SetTextRenderingParams, GetTextRenderingParams, SetAntialiasMode, GetAntialiasMode}

// ── Layers: the one group operator ────────────────────────────────────────────
// A layer applies a geometric mask, an opacity mask and a group opacity to a *set* of
// primitives; everything else Direct2D offers is per-primitive. `ID2D1Layer` appears
// only so the null argument has a type — `CreateLayer` is deliberately not carried,
// because passing null is what lets Direct2D own the intermediate and share it with
// effect intermediates. `INITIALIZE_FROM_BACKGROUND` skips the clear to transparent
// black; `IGNORE_ALPHA` is legal only when the target surface itself ignores alpha, so
// it is selected from the target rather than from the call site.

// ── Bitmaps and sprite batches ────────────────────────────────────────────────
// Blits are `DrawBitmap`; effect outputs are `DrawImage`. There is no general image
// draw: `DrawImage` accepts any `ID2D1Image` and runs Direct2D's image command graph
// to discover what it was handed, which for a bitmap is an order of magnitude of
// pure overhead (2473 samples against 108, for six blits a frame).
//
// `Map` and `CopyFromBitmap` exist for readback: a CPU-readable staging bitmap is how
// the parity rig and the FP16 round-trip test observe what was actually drawn,
// including the above-white and negative components the pipeline exists to carry.
    ID2D1Bitmap::{GetSize, GetPixelSize, CopyFromBitmap}

// One `DrawSpriteBatch` draws N rectangles sampled from one bitmap, where N
// `FillRectangle` calls are N primitives — the documented way to put "hundreds or
// thousands of images" on screen per frame. `SetSprites` rewrites an existing batch
// in place, so a field that changes every frame costs no allocation. Deliberately
// NOT taking `GetSprites`: nothing here reads back.
// The clamp option exists for sampling a *sub-rectangle* of a source with linear
// filtering, which needs per-sprite source rectangles — and a field wanting those is two
// batches rather than one, so nothing here can be in the position that needs it.
    ID2D1SpriteBatch::{AddSprites, SetSprites, GetSpriteCount, Clear}
    D2D1_SPRITE_OPTIONS_NONE

// ── Effects: deliberately not here ────────────────────────────────────────────
// Nothing in this stack builds an effect graph, so `ID2D1Effect`, `ID2D1Properties` and
// the effect CLSIDs are absent rather than carried unused. What stays is the buffer
// precision the device sets at construction, which is the part that matters: Direct2D
// makes no guarantee about if or where it materializes a graph's intermediates, and
// their default precision is limited-range — so a graph built without it would silently
// clamp exactly the extended-range values this stack exists to carry. Setting it before
// any caller sees the context means a graph added later inherits it and cannot be built
// without it.
//
// Two doors stay shut on purpose. The colour-management effect scales G2084 input by 125
// during degamma, and PQ appears in this stack only inside an ICtCp value, never as a
// surface encoding.
    D2D1_BUFFER_PRECISION
