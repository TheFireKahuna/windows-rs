// ── Whether anything drawn can be seen ────────────────────────────────────────
// Two independent questions with no single API for either half. The window's own — not shown
// yet, minimized, or cloaked by the shell or by a virtual-desktop switch — is
// `IsWindowVisible` plus `IsIconic` plus `DWMWA_CLOAKED`; a cloaked window is still composed
// by DWM, so nothing else reports it. The system's is `RegisterOcclusionStatusWindow`, in its
// message form because this thread has a pump already.

    DWMWA_CLOAKED
